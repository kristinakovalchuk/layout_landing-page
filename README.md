# MyBike Landing Page

A responsive landing page for a bicycle brand, designed to showcase various bike models and detailed features. The project focuses on semantic HTML structure, styling with BEM methodology, and responsive layout without the use of JavaScript functionality.

## 🔗 Links

- **Live Preview:** [Click here to view the website](https://kristinakovalchuk.github.io/layout_landing-page/)
- **Design Layout:** [MYBIKE landing](https://www.figma.com/file/NZQAIydtHo5QkINyGLHNcq/BIKE-New-Version?node-id=0%3A1)

## 🛠 Built With

- **HTML5**: Semantic tags structure (`<header>`, `<main>`, `<section>`, `<article>`, `<aside>`).
- **CSS3**: Custom properties, Flexbox for layout, and responsive media queries.
- **BEM**: Block Element Modifier methodology for organizing CSS classes.
- **Google Fonts**: Poppins fonts integration.

## 📄 Project Description

The "MyBike" project is a layout implementation of a marketing website. It includes:
- **Header**: Navigation and branding.
- **Hero Section**: Engaging visual introduction.
- **Features Section**: "Move Free" descriptive block.
- **Comparison Block**: Cards displaying different bike models with prices and descriptions.
- **Details Section**: Grid layout highlighting specific bike features (Auto Unlock, Battery Range, etc.).
- **Contact Form**: A styled form section with contact information and Google Maps link.
- **Mobile Menu**: Responsive side menu layout (markup prepared).
